# Agriculture Crop Production Prediction

## Project Overview
This project predicts agricultural crop yield using Machine Learning techniques. The model analyzes cultivation and production-related factors to estimate crop yield and help improve agricultural decision-making.

## Features
- Data Preprocessing
- Exploratory Data Analysis (EDA)
- Statistical Summary
- Yield Distribution Visualization
- Correlation Heatmap
- Feature Importance Analysis
- Crop Yield Prediction using Random Forest Regression

## Dataset
The project uses agricultural crop production datasets containing cultivation costs, production costs, crop information, and yield values.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

- eda.py

The project generates:
